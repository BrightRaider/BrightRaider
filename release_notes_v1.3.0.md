# BrightRaider V1.3.0 — BrightRaider grows up

> 🧪 **Pre-release.** Settings, profiles and license carry over.

BrightRaider started with one job: make the dark corners of Arc Raiders readable. **With V1.3 it grows up.** The core is now a tool for **every game** — colours, FPS, sound, crosshair, autorun — and **Arc Raiders becomes its first module**, with its own page and its own switch. A setup walks you through all of it, and every page explains itself.

| | |
|---|---|
| 🧭 **Setup assistant** — at the first start and once after this update, filled with what you already have | ⚡ Free |
| 🗂 **New settings window** — a sidebar, every key on the page of its feature, a guide beside every page | ⚡ Free |
| 🖥 **G-SYNC / FreeSync setup** — the Blur Busters way, with an exact Undo | ⚡ Free |
| 🔔 **Notifications on the screen you choose** | ⚡ Free |
| 🎮 **Arc Raiders as a module** — all four tools under Modules, one switch for all | 🔓 Pro |

**🧭 Setup** — every page already shows your settings: *Next* keeps them, only what you change is changed. New things are marked *New in 1.3*. It never opens over a running game. Again any time: *App & License → Run the setup…*

**🖥 G-SYNC / FreeSync** — V-SYNC and low latency in the driver, an FPS limit just under your refresh rate (144 Hz → 138), competitive games can be left out (NVIDIA). Why: [Blur Busters — G-SYNC 101](https://blurbusters.com/gsync/gsync101-input-lag-tests-and-settings/14/). 🧪 *AMD owners: I could only test on NVIDIA — please tell me how it went.*

**🔧 Fixed** — strong profiles did nothing until Windows was restarted (#86); now they apply as far as Windows allows. Any FPS limit in the setup, dark title bars everywhere.

Every setting from V1.1 and V1.2 was checked key by key — if anything is not where you left it, tell me in the [Discussions](https://github.com/BrightRaider/BrightRaider/discussions). Thank you to everyone who tested and reported: this one grew up because of you.
