[ V1.2.3 ] - Pre-release

  Fixed (what you reported after V1.2.2)
  - First start: the setup and the "ready" notice say that Windows needs one
    restart for the full brightness range (#86). Until then strong profiles
    can be refused.
  - QuickSave finds the raid inventory (#85): the inventory sits in another
    place in a raid than in the hideout, and on 4:3 and 16:10 at the top or in
    the centre. QuickSave looks at the open inventory and aims where it really
    is, on every screen shape.
  - Game mute works again after you restart the game. The mute icon no longer
    takes the focus off the game; in exclusive fullscreen Windows shows no
    overlays, so the icon needs borderless.
  - Once the mute icon had been shown, Alt-Tab could stop switching your colour
    profile and the dimming until the next start. Fixed.
  - Mute teammates ends by itself when the game closes or BrightRaider is
    switched off. The tray menu has "Unmute teammates" while they are muted. A
    voice app that starts after BrightRaider is unmuted as soon as it appears.
    Free users now see which hotkeys are Pro.
  - Dim other displays follows the screen the game is on, comes back with the
    Global ON/OFF key, and works with Alt-Tab auto-switch off. If BrightRaider
    is killed or crashes while the other screens are dimmed, a small helper
    process (started with the dimming, gone after a normal exit) puts them back
    within a second or two, and takes back an FPS limit set in the driver.
    "Re-capture original gamma" no longer saves a dimmed screen as its
    original. After you enable the extended gamma range the dimming stops at
    60 % until Windows has been restarted; the Display tab says so.
  - FPS limit: BrightRaider puts back exactly what it changed. A cap you set
    in the NVIDIA Control Panel is no longer removed. The driver reads the
    limit when the game starts: after you add or change one, close the game
    once and start it again.
  - F5 for the Autoscrapper only works in the game. Other Unreal games are no
    longer taken for Arc. Autorun stops when you switch to another program.
  - A second screen with HDR no longer hides the profile notice. The Windows
    question for the extended gamma range is not asked again and again.
  - The "What's new" notice for people coming from V1.1.1 now describes the
    Autoscrapper.


[ V1.2.2 ] - Pre-release

  Map Scanner
  - New event: ARC Frigate (any map). All evac points stay open and there are
    no Raider Hatches; the overlay header adds "No Hatches".
  - The triangle in front of major events (Matriarch, Hurricane, Night Raid,
    Electromagnetic Storm) is gone from the overlay header.
  - Pendola Pass, the new map, is recognised by its name and the overlay lists
    its four gondola points: open ones run the raid's remaining time (the same
    on each), closed ones show CLOSED; at night only two are open. The gondola
    has no countdown of its own, so the evac alarm follows the raid timer.
    Recognised on its own in the German game UI so far; in other languages it
    still shows up under the Redirection condition.

  Display and audio
  - Much faster Alt-Tab into and out of the game: the work BrightRaider does
    on every focus change got much lighter.
  - New: "Dim other displays" (Settings -> Display). A slider darkens every
    screen except the one the game is on while a game is in front;
    Alt-Tab brings them back. Applies like the other colour settings: only
    while the game is in front, after Apply / OK; "Test on screen" flashes it
    together with the profile. A key (Settings -> Hotkeys -> Dim on/off)
    switches the dimming off and on during the session, e.g. for a film on
    the other screen. Goes down to a tenth of the normal brightness
    with the extended gamma range, about 60 % without it. 0 = off. Free.
  - New: "Mute teammates" (Settings -> Hotkeys, Pro). One key mutes or unmutes
    your voice chat apps. Pick them from a list: Discord, TeamSpeak, Mumble,
    Teams and Zoom are already in it, "+ Add app..." takes any running program.
    Unbound by default. A mute left behind by an exit or crash is undone at the
    next start.
  - The Windows permission prompt for the extended gamma range is asked once;
    after a "no" a button in Settings -> Display asks again.
  - New: small mute icons in the top-left corner of the game's screen: a
    speaker with a cross while the Mute hotkey has the game silenced, a
    headset struck through while Mute teammates has your voice chat silenced.
    Switch them off in Settings -> Audio. They never take clicks or focus.

  Fixed
  - QuickSave on 4:3 and 16:10 screens (#83, #85): the inventory is not in the
    same place in the hideout and in a raid, and on such a screen it sits at
    the top or in the centre. QuickSave now looks at the open inventory and
    aims where it really is, instead of assuming one place.
  - Notifications (toasts) always appeared on the primary monitor (#85). They
    now follow the monitor you picked in Settings, or the one the game runs on.
  - Numbers in fields with up/down buttons were cut off when the field was
    narrow ("72" showed as "7"); they keep room for the digits now, in every
    window.
  - The game mute key needed two presses to bring the sound back when the game
    had been muted by something else (Alt-Tab background mute, the Windows
    mixer, an earlier run). It now looks at the game's real mute state and the
    toast reports what the audio actually is afterwards. Same for Mute
    teammates.
  - QuickSelect, QuickSave and the Map Scanner key only act while the game is
    in front; elsewhere the key goes through untouched.
  - On Free, the keys of Pro features (Num4-9, mute, crosshair, audio device,
    ...) and the Arc toggle keys with Arc off no longer swallow the key in
    other programs. The Global ON/OFF key follows "only while a game is
    focused" unless it is on the numpad.
  - A colour curve Windows does not take (HDR on, extended gamma range
    missing) is reported once with the likely cause, instead of toasting
    "Profile 2".
  - A game profile without an FPS value no longer writes 0 into the driver.
  - Autorun stops when hotkeys are switched off or the game is left.
  - Under the hood: sturdier hooks and startup, and safer loading of
    graphics-driver libraries.

  Autoscrapper
  - Everything it already knew that is not a weapon is recognised as
    reliably as before - those are usually the items you want handled
    automatically.
  - Items added by the Frozen Trail update are only partly known yet. A tile
    that cannot be named is never touched; the item data is extended step by
    step. You can teach it yourself: name an unrecognised item once under
    Settings -> Autoscrapper -> Name unrecognised items... and it is
    recognised from the next scan on. Weapon pictures get smaller the more
    attachments a weapon carries and everybody runs different ones, so
    weapons need a different approach; until then a weapon that cannot be
    named is left untouched.
  - About twice as fast. No scrolling at the start when the stash is already
    at the top, and from further down it drags the scrollbar instead of
    wheeling. The scan stops at your last item, and a run stops as soon as no
    remaining stack fits what may still go.
  - Picks the stacks that hit your keep amount: "keep 40" over stacks of
    10,10,10,10,10,10,7,5 now leaves exactly 40, not 42.

  Fixed
  - A row skipped while scrolling is now fetched even when the stash is not
    full; the scan used to come back incomplete.
  - Clicks could land a row off when the list was still moving after a
    scroll.
  - After a test run the item tooltip could cover the stash and stop the run.
  - The Windows lock screen was taken for a game and switched to the game
    profile, so it came up brighter.


[ V1.2.1 ] - Pre-release

  Autoscrapper
  - New, optional: run without the review. Once your rules are settled, F5
    scans and runs them straight away. Items without a rule and unnamed tiles
    are still never touched; if the scan missed part of the stash, the review
    comes up anyway. Off by default.
  - After the scan it works upward from the end of the list instead of
    scrolling all the way back to the top first.
  - Damaged items are no longer mistaken for their blueprint.
  - Stack counts: a 9 no longer reads as 8, a 4 no longer as 0 or 9.
  - The review no longer warns that the scan missed part of the stash when
    the stash is simply less than three-quarters full.

  QuickSave
  - Fixed on 4:3, 16:10 and stretched resolutions (#83): the inventory is
    anchored at the top, not centred, so every target sat too low.
  - W1/W2 grabbed the first attachment (the barrel) on weapons with four
    attachments. All drops now land on the slot centre.

  General
  - Running an older version in between no longer loses your newer settings:
    they are restored on the next start.


[ V1.2.0 ] - Pre-release

  New: the Autoscrapper

  - BrightRaider can now read your stash off the screen, work out what every
    tile is, and show you a list of what it would scrap or sell. Around 300
    slots over 80-odd rows in about ten seconds.
  - Nothing happens until you press Run. The review screen cannot be skipped,
    and an item that is not on your list is never touched — that is the whole
    safety model in one sentence.
  - The review screen IS the rule list. Set "keep 200, scrap the rest" while
    looking at the actual item, with its picture, how many you have and what
    one is worth. Pressing Run also writes those choices back as rules, so the
    second run needs no editing at all.
  - Two run modes, and the safe one is the default. Test run goes the whole
    way — picks the tiles, presses the key, waits for the game's own
    confirmation box — and then closes that box with Escape instead of
    confirming it. Everything except the last click, and nothing is lost. Only
    Live acts. (Two quieter modes, Probe and Rehearsal, are still reachable
    through the config file for anyone who wants them.)
  - The review screen tells you what your decision is worth. Beside every row
    is "Worth of the rest": type 10 into the keep box and it shows, at once,
    what the other 7 are worth altogether — before you have picked what happens
    to them, and on a scrap row too, where it is what you are giving up. The
    header adds the sales up for the whole run and tells you what everything on
    the screen is worth in total. Only a sale is counted as money coming in:
    scrapping returns materials, not credits, and a credit figure there would
    be a number you never get.
  - Some items are drawn identically by the game. The two Looting Mk. 3
    blueprints are pixel for pixel the same picture, and a modification
    blueprint carries neither a tier numeral nor a rarity crescent — there is
    nothing on the tile to tell them apart, so BrightRaider does not guess. The
    row shows both names, and asks a different question instead: do your rules
    say the same thing about both? If they do, the name never mattered. If they
    differ, the row is left alone and says why.
  - Anything it cannot name goes into a naming queue with its picture. You name
    it once and it is recognised from the next scan on. Names you give are kept
    in your own file and no update ever overwrites them — and if the item is one
    the built-in list has never heard of, you can simply type the name.
  - Every resolution: 1080p to 5K, 16:10, 4:3 and 21:9 ultrawide. Checked in
    game at 1080p, 1440p, 4K, 5K, 16:10 and 4:3 — every slot found, no wrong
    names, no stack count off.
  - Damaged items are recognised only from a picture of a damaged one. The red
    triangle sits inside the artwork and changes the fingerprint by about fifty
    bits, so an undamaged reference cannot match it. Until you have named one,
    such a tile stays unidentified — which means untouched.

  Also new:

  - GPU picker and display index: choose which adapter and which monitor
    BrightRaider drives.
  - Autorun per game: the sprint key, hold-or-toggle, and the tap timings can
    now differ per game profile.
  - Map events are marked major or minor.
  - BrightRaider checks for updates through its own endpoint, with a guard
    against a stale feed serving an old version for ever.
  - Controller support is answered in the README FAQ.


  Fixed:
  - Game mute, audio ducking and the Footstep Booster could quietly do
    nothing if you listen through a headset that registers more than one
    playback device — an Astro A50 shows up as both "Game" and "Voice", and
    BrightRaider only ever changed the FIRST entry it came across, which was
    often not the one you were hearing. The same thing happened when your
    game had left an entry behind on a device you had since switched away
    from. Mute and ducking now cover every output the game is using, and
    ignore entries belonging to a device it has already left. This goes back
    to V1.0 in one form or another — V1.1.0 fixed the half where your game
    played on a device that wasn't your default one, this fixes the rest.
  - The Footstep Booster could attach itself to a silent output of the game
    instead of the one actually playing, on the same multi-device headsets.
    It waits for the output that is really making sound now.
  - Closing BrightRaider while a game sat in the background left that game
    muted in Windows — permanently. Background mute only ever undid itself
    when you Alt-Tabbed back into the game; shutting down in that state undid
    nothing, and the game stayed silent with BrightRaider no longer running to
    explain it. Shutdown now unmutes it.
  - If BrightRaider is killed or crashes while a game is muted or ducked, that
    game no longer stays quiet afterwards. The change is written down as it
    happens and undone the next time BrightRaider starts — or the next time
    that game comes to the front, if it isn't running yet — with a note saying
    what was put back.

  Small fixes & polish:
  - New button, Settings -> Audio -> "Reset game audio": unmutes the running
    game and, where BrightRaider recorded your level beforehand, puts that
    level back. Mute, background mute, ducking and the Footstep Booster all
    work by changing the game's entry in the Windows volume mixer, and a crash
    at the wrong moment leaves that change behind — one click undoes it. It
    never pushes your volume to 100% on a guess; if the old level isn't known
    it tells you where the slider stands and leaves it to you.
  - BrightRaider now speaks up on its own: if a game comes to the front while
    its mixer entry is muted, or sits exactly at your ducking level, you get a
    warning that names the reason and the fix instead of a silent game.
  - The tap-timing fields under Movement were too narrow and cut off the
    last digit — with the recommended 1300 ms interval you couldn't read
    what you had set. Both fields, and their per-game copies, are wide
    enough now.
  - The debug log now records how many outputs mute and ducking changed, so
    "it did nothing" is visible in the log instead of invisible.


[ V1.1.0 ]

  New in V1.1:
  - Map Scanner now works with other games via downloadable data packs —
    drop a game's pack into the packs folder and its maps, timers and
    conditions are read the same way as Arc Raiders. (See the pack authoring
    guide.)
  - Map Scanner recognises more Arc Raiders map conditions, including
    Uncovered Caches and Hidden Bunker (Spaceport). Hidden Bunker also
    reduces the active evac points and marks the closed hatches.
  - Per-game Auto-HDR: turn Windows HDR on automatically when a chosen game
    launches, off again when it closes. Opt-in per game; Alt-Tabbing in and
    out never flips HDR — it only switches on real game start/exit.
  - New "Movement" tab: Autorun now lives in its own tab, separate from the
    general hotkeys.
  - QuickSave can now swap items to and from your backpack slots, not just
    the Safe Pocket (Backpack 1-4).
  - QuickSelect wheel: pick the target slot from a simple "Slot 1-10"
    dropdown instead of typing a number.
  - Arc Raiders features are now an optional module. A fresh install starts
    as a pure display / FPS tool; enable the Arc Raiders module in the setup
    wizard (or Settings -> App) to add the map scanner, QuickSelect,
    QuickSave and Autorun helpers. Existing users keep it on. Free stays
    free; Pro is unchanged.

  - "Deactivate on this device" (Settings -> App, License): frees your
    license's activation slot for this PC in one click, so you can move to
    a new machine yourself — no support ticket needed.
  - Color-conflict warning: if another tool that controls your display
    colors is running (f.lux, Iris, Windows Night Light, ...), BrightRaider
    now tells you at startup and on the Display tab. Those tools and
    BrightRaider fight over the same gamma pipeline — this was the most
    common cause of "my colors keep reverting".

  - Autorun tap mode: new recommended timings. A recent Arc Raiders patch
    nerfed the Looting Mk. 3 (Survivor) augment, and the old 990 / 169 ms
    pair no longer got you anywhere. New defaults are 1300 ms interval /
    160 ms press — you move forward again and regain some health. Existing
    setups keep their own values (settings are never overwritten); set them
    under Settings -> Movement -> Tap Interval, and BrightRaider reminds you
    once after updating if you are still on the old pair. The nerf is still
    harsh — taking "Crawl Before You Walk" (yellow skill tree, top middle)
    is strongly recommended, crawling gets far faster with it.

  Small fixes & polish:
  - Notifications are now color-coded: green = good news (update
    available), yellow = warning, red = risky mode active.
  - Option to mute the QuickSelect / QuickSave confirmation toasts
    (Settings -> App).
  - The "Hotkeys enabled" toggle now stays in sync everywhere the moment you
    change it.
  - The global hotkey-toggle binding is shown on the App tab.
  - Cleaner QuickSave slot list (dropped the redundant "#" column).

  Fixed:
  - Turning on one of the Pro profiles 4-9 did not survive a restart —
    the profile was back to disabled on the next launch. (The setting was
    only written to disk when a profile was switched OFF.)
  - QuickSave could stop working entirely if you had a cooldown set for a
    preset — the trigger did nothing, whatever you rebound it to. (Found
    during the V1.1 pre-release, never shipped in a stable build.)
  - The "Alt-Tab Auto-Switch" checkbox on the Game Profiles tab was ignored
    when you pressed Apply (the App tab's copy won), and toggling it from the
    tray while Settings was open got undone on Apply. Both work now.
  - Game mute, audio ducking and the Footstep Booster only ever looked at your
    DEFAULT playback device. If your game played on a different device — or
    BrightRaider's own audio switcher had just changed the default — they
    silently did nothing. They now find the game on any active output device.
  - Audio ducking restored the game to 100 % volume instead of the level you
    actually had. It now puts your own volume back.
  - The Footstep Booster and audio ducking fought over the same volume: with
    the Booster running, ducking was undone within a fraction of a second.
    They now cooperate.
  - The Process Optimizer now really does hand priority and CPU affinity back
    when you Alt-Tab out or quit — as the manual has always described.
  - Assigning a hotkey that clashes with the HDR toggle or the audio-device
    key gave no warning at all, and the clashing key then did nothing. Those
    two are now included in the conflict check.
  - On some systems the first-launch admin prompt came back on EVERY start
    (when another calibration tool had written its own value). It's a one-time
    prompt again.
  - The Auto-Brightness zone boxes were drawn in the wrong place on displays
    with Windows scaling (125 % / 150 %), so they didn't mark the spots
    actually being measured. They line up now, and they follow along when you
    switch monitors.
  - A stray timer overlay could reappear for a moment while BrightRaider was
    closing.
  - If you deleted your last game profile while the game was running, the
    audio device never switched back.
  - Much quieter debug log: BrightRaider no longer writes a line every time
    ANY window on your PC gets focus.

  - Many more under-the-hood reliability fixes from four rounds of code
    review: safer restore of your FPS limit and display calibration on exit,
    macro timing that no longer trips over Windows clock changes, hardened
    handling of downloaded game packs, and various race fixes in hotkey
    handling, the evac countdown and startup/shutdown.

  Everything from V1.0 carries over — settings, profiles and license are
  kept, no re-activation needed for this update.


[ V1.0.0 ]

  The V1.0 release. Major rewrite on .NET 9 + Native AOT + Avalonia UI.
  One EXE, no installer, no .NET runtime required.

  Upgrade note for V9.x users:
  - Settings, profiles, hotkeys, and game profiles migrate automatically
    on first launch.
  - License key must be re-entered once (Settings -> App -> Enter license).
    Lemon Squeezy re-issues the activation instantly — same email, same
    key, no re-purchase. V1.x updates after this won't require another
    re-entry.

  New in V1.0:
  - Map Scanner (Pro): long-press M -> on-screen overlay with live evac
    timers, map + event auto-detection, color-coded warnings, audible
    alarm at configurable threshold.
  - Auto-Brightness (Pro): per-profile brightness ranges, 5-zone screen
    sampling, smooth Gamma/Contrast/Vibrance interpolation. Includes a
    Calibration Wizard.
  - Footstep Booster / Loudness Limiter: per-process audio compressor —
    cap the game's audio session at a threshold so you can crank in-game
    volume to make footsteps audible without going deaf on gunshots.
  - Background mute: auto-mute the game's audio session when Alt-Tab'd
    out, restore on focus return.
  - Process Optimizer: opt-in High priority + physical-cores-only affinity
    for the foreground game.
  - Alt-Tab Auto-Switch: per-game color profile + FPS limit + crosshair
    state, applied in one GPU call (no double-push / no AMD gamma-stuck).
  - Update notifier in the tray menu.
  - Per-profile tray icon color, ●-marker for active profile.
  - Configurable hotkeys (no more separate Arrow EXE).
  - Resizable Settings window with sidebar tabstrip; dark mode.

  Free features stay free. Pro adds Auto-Brightness, Map Scanner,
  QuickSelect, QuickSave, Footstep Booster.

  Bug fixes vs V9.6.1:
  - Original gamma ramp is saved to disk on first launch and reloaded
    every startup. A crashed or force-killed BrightRaider can never
    poison the saved baseline — your DisplayCAL / ICC calibration is
    safe across any crash.
  - New App-tab buttons: "Reset to neutral now" pushes a known-clean
    gamma immediately. "Re-capture original gamma" updates the saved
    baseline to the current state (use after recalibrating).
  - Config saves are atomic (.tmp + replace + .bak fallback) — no more
    corrupted config on power loss / crash.
  - Single-instance lock — second launch raises the existing window
    instead of running two copies.
  - Break reminder now respects the live toggle — turning it off in
    Settings stops the timer immediately (was: needed app restart).
  - Calibration Wizard: buttons readable on dark theme, live value
    updates immediately, Enter reliably confirms each step.
  - Auto-Brightness respects the global On/Off hotkey (was: kept
    pushing gamma even when BrightRaider was supposedly off).
  - Tray toggles and Settings dialog stay in sync — toggling Alt-Tab
    or Auto-Brightness via the tray no longer gets clobbered when the
    Settings dialog is open.
  - Settings window remembers its size between launches.
  - Modifier-key bindings (Ctrl+, Alt+, Shift+ combinations) are
    fully supported and documented inline in the binding tabs.

  Pre-release updates (shaped by tester feedback — thanks @DBasic,
  @Tia-Nastacia and @dawuus):

  New in this window:
  - HDR toggle hotkey (Free): flip Windows HDR on/off with one key
    instead of digging through Windows Settings. Pinned-monitor aware,
    unbound by default; your color profile is re-applied after the mode
    switch.
  - Audio Output Switcher (Pro): switch the default output device
    (speakers <-> headphones, or cycle any set you choose) with one
    hotkey. Optional auto-switch to a chosen device when a game starts,
    restoring the previous one when it closes (Alt-Tab does NOT switch
    back). Moves the game/media device only by default; an opt-in "Also
    switch the communications device" makes Discord/voice follow too
    (off by default so voice apps like TeamSpeak aren't disrupted).
  - "Apps to ignore" list (Game Profiles tab): fullscreen windows that
    aren't games (browser video, media players) are left completely
    alone -- no overlays, no color change, no FPS cap. Common browsers
    and players are excluded out of the box.
  - "Only run hotkeys while a game is focused": optional gate so
    BrightRaider's keys never interfere with desktop typing.

  QuickSelect / QuickSave rework:
  - QuickSelect: per-slot LMB hold time typed directly in ms (the old
    T1-T6 preset table is gone), five common heals pre-filled, a Timing
    reference button, and the post-use action correctly labeled Holster.
    Wheel slots 3-6 are selected by their in-game number key (immune to
    mouse movement); 7-10 use the cursor.
  - QuickSave: From/To are plain dropdowns named like the in-game
    inventory (Slot 1-5 / Augment 1-3 / W1-W2 / P1-P3); the trigger
    toast reads e.g. "W1 -> P1" (or "W1 <-> P1" for toggle presets). An
    in-app hint explains the timing (Drop hold is the key setting).
  - Both tabs: a "Slot layout" button shows the annotated in-game
    loadout and a "Guide" button opens the full guide. Existing presets
    and timings migrate automatically.

  Display & overlays:
  - Brightness profiles match the V9.6.1 look again; "Brighter" is
    usable.
  - Nvidia Hue runs 0-359 like the Control Panel (was a centered
    -180..+180). Range still adapts to your GPU.
  - Overlays (crosshair, map scanner, timers) stay on the monitor you
    pin, and anchor to the game's monitor on "All Monitors" instead of
    chasing whatever window you click; vibrance/hue apply to the pinned
    monitor only.
  - Pinned-monitor startup fix (vibrance no longer flashes on all
    monitors at launch); a monitor plugged in after launch restores its
    original gamma on exit / Alt-Tab.

  Input & hotkeys:
  - No input freeze on Alt-Tab and no "stuck" mouse button -- the
    keyboard/mouse hooks run on their own thread; the held-click macro
    path was hardened too.
  - Fixed a system-wide stuck Shift with Autorun running (symmetric
    swallow so key-repeat can't latch Shift).
  - Modifier + mouse bindings work (e.g. "Ctrl + Wheel up", "Shift+MB4").
  - Global On/Off key is swallowed on every edge and no longer leaks to
    the game or other apps.
  - While a rebind field is waiting, hotkeys/macros pause so the key you
    press is captured cleanly instead of firing.
  - Autorun: crouch (C) is no longer blocked after you take over a
    sprint with W; tapping C now slides and keeps running.
  - Number fields reject letters and other non-numeric input.
  - Crosshair outline thickness is adjustable (1-5), separate from the
    outline color. Every slider takes the mouse wheel and has a type-in
    field; an "Advanced" toggle hides the millisecond-timing fields.

  Map Scanner:
  - Verified 100% accurate across resolutions and aspect ratios
    (16:9, 16:10, ultrawide, 2560x1600, etc.).
  - A map with no condition shows just its name (no redundant "Normal").
  - Evac alarm: plays its own audible tone (independent of your Windows
    sound scheme), optional repeat, color-coded toast, re-arms per evac
    point, and stays silent whenever the scanner overlay is hidden.

  Reliability & polish:
  - Full code-review stability pass across input hooks, audio device
    switching, macro injection and the map scanner.
  - Settings backup now actually recovers a corrupted config instead of
    resetting to defaults.
  - Audio device switch no longer crashes voice apps (game/media only by
    default; rapid presses handled cleanly).
  - License: activation unlocks Pro live (no restart); the saved license
    persists even if the store omits the email.
  - Lower-overhead Auto-Brightness sampling (reuses one GDI surface
    across all five zones); the "Center" zone weight now applies to the
    actual center zone.
  - Sharper app icon at small sizes (Task Manager, Explorer, title bar).
  - Right-click the version line to copy full system info for bug
    reports; the version line flags when an update is available.
  - Fixed: re-running the Setup Wizard from an open Settings window is no
    longer overwritten by the dialog's next Apply.


[ V9.6.1 ] - Previous Version

  Bug fixes:
  - Fixed: Mouse stutter and game input lag while BrightRaider is running.
    Config saves and menu rebuilds were happening on the Windows keyboard hook
    thread, which has a strict ~300ms OS timeout. This stalled the entire input
    system — mouse movement, key presses — especially noticeable on fast GPUs
    and 4K displays. Both operations are now dispatched asynchronously.
  - Fixed: Auto-Brightness caused unnecessary GPU wake-ups on every tick
