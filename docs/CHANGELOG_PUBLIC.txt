================================================================
  BrightRaider - Changelog
================================================================


[ V9 ] - Current Version

  Map Scanner (Pro):
  - New: Hold M on the map to scan all evacuation timers automatically
  - Zooms out, reads all evac points via OCR, starts countdown overlay
  - Supports 5 maps: Buried City, Stella Montis, Space Port, Blue Gate, Damm
  - Color-coded countdown: green (>10 min), yellow (>5 min), orange (>1 min), red (<1 min), gray (closed)
  - Auto-calculates missing timers when one point is partially obstructed
  - Adjustable hold duration (how long to press M) in Map Scanner settings
  - Overlay position: 6 screen positions to choose from
  - Customizable overlay color and font size with live preview
  - Powered by Windows built-in OCR — takes a screenshot, reads timers from it (no game files or memory touched)
  - Works on any resolution (auto-scales from 1080p baseline)

  Timer Overlay:
  - Toggle timer overlay on/off: Numpad* (Numpad version) / Delete/Entf (Arrow version)
  - Toast notification when toggling (consistent with other toggles)

  Arrow Keys Edition:
  - Arrow version now also includes Map Scanner (previously unchanged from V8.1)
  - Hold M on map to scan timers (same as Numpad version)
  - Delete/Entf to toggle the timer overlay on/off

  Crosshair Fixes:
  - Fixed: Crosshair now pixel-perfectly centered on all resolutions
  - Fixed: Changing style or size in settings no longer reverts to previous values

[ V8.1 ]

  Vibrance Restore:
  - New: BrightRaider now reads your current Digital Vibrance on startup
  - Profile 1 "Normal" restores your personal vibrance setting (not default 50)
  - On exit, your original vibrance is fully restored
  - Works with NVIDIA and AMD GPUs

  Hotkey Pause:
  - New: Pause hotkeys in Settings when you need your numpad/arrow keys elsewhere
  - BrightRaider stays running, just stops intercepting keys
  - Setting is saved and persists across restarts

  Fixes:
  - Fixed: Update check now works reliably (TLS 1.2 for GitHub/Lemon Squeezy)

[ V8 ]

  Crosshair Overlay (Pro):
  - New: Click-through crosshair directly on your screen
  - 4 styles: Cross, DotRing, TShape, Dot
  - Customizable color and size (10-50px)
  - Toggle: Numpad+ (Numpad version) / Insert (Arrow version)
  - Live preview in settings
  - EAC-safe — same mechanism as Discord overlay

  Auto-Start (free for all):
  - Auto-Start with Windows is now available for all users, not just Pro

  Update Check:
  - Automatic update notification on startup (can be disabled in Settings)

  Security:
  - Hardened license validation — tampered .lic files are now rejected
  - Note: One-time re-activation required for existing Pro users

  UI:
  - Monitor selection moved from Settings submenu to main menu
  - Settings submenu is now compact (no overflow on small screens)

[ V7.2 ]

  Security & Compatibility:
  - Added assembly metadata (version info visible in file properties)
  - Added Windows compatibility manifest (Windows 10/11)
  - Optimized build — reduced antivirus false positives
  - Thanks to @bedub for reporting the VirusTotal flags

[ V7.1 ]

  Multi-Monitor:
  - Fixed: Debug overlay, calibration wizard and toast now appear on the selected display
  - Fixed: Brightness measurement now targets the correct monitor
  - Fixed: Switching monitors no longer requires app restart

[ V7 ]

  License Activation:
  - Fixed "Key belongs to a different product" error
  - Added validate fallback for already-activated keys
  - Removed redundant product validation checks
  - Activation now works reliably on first try
  - Note: Requires re-entering license key once after update

  Arrow Keys Edition:
  - New: BrightRaider_Arrows.exe for keyboards without numpad
  - Arrow Left/Down/Right = Profile 1/2/3
  - Arrow Up = Mute/unmute game (Pro)
  - Same features, same license — just different hotkeys

[ V6 ]

  License:
  - New: Lemon Squeezy — buy Pro, receive key instantly by email
  - One-time online activation, offline forever after

[ V5 ]

  Auto-Brightness (PRO):
  - Automatic brightness adjustment based on screen content
  - 5-zone X-pattern measurement (center weighted 2x)
  - Smooth interpolation between profiles
  - Calibration wizard for easy setup
  - Configurable update interval

  PRO Features:
  - Up to 9 profiles (Numpad 1-9, free limited to 3)
  - Custom profile editor (Gamma, Contrast, Vibrance per profile)
  - Auto-Start with Windows *(free for all users as of V8)*
  - Game Mute toggle via Numpad 0
  - Debug Overlay for fine-tuning

  Menu & UI:
  - Clean, compact tray menu with Settings submenu
  - Instant custom notifications (no Windows delay)
  - Multi-monitor support with per-display selection
  - Notification toggle
  - Bilingual (English / Deutsch)
  - PRO status displayed in menu

  General:
  - Embedded icon — single .exe, nothing else needed
  - Encrypted config and license files
  - Individual license keys per customer
  - Single portable .exe (~65 KB), no installation needed
  - Offline license validation — no internet required
  - Works with NVIDIA, AMD and Intel graphics

[ V4 ]
