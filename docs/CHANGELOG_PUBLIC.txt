================================================================
  BrightRaider - Changelog
================================================================


[ V9.6 ] - Current Version

  Map Scanner (Pro):
  - New: Riven Tides map added — Coastal Lift and Customs Lift.
  - New: Night, Hurricane, and Electromagnetic Storm event detection.
    The overlay shows the active event name next to the map name.
    Evac points are automatically adjusted per event type:
    Night → 2 active points, Electromagnetic Storm → 3, Hurricane → all standard.
    Excess points are shown as CLOSED immediately, without waiting for a timer scan.
  - New: "⚠ Raider Hatches closed" warning shown during Night and Storm events.

  Crosshair:
  - New: Outline option for all crosshair styles — configurable outline color,
    improves visibility on bright backgrounds.
  - New: Outline rendering rewritten (Cross, CrossGap, TShape) — now pixel-perfect
    and symmetric at all sizes. Fixes the left-side misalignment visible at small sizes.
  - New styles: Ring (circle only) and Cross-with-gap (CS:GO-style with adjustable gap size).
  - Fixed: Cross-with-gap disappeared below 6px. Also fixed: sizes 6 and 7 looked identical.
    Arms are now visible at any size.
  - Fixed: Dot crosshair is now a circle, fully adjustable via the size slider
    (was previously fixed at 7×7px regardless of slider position).
  - Minimum crosshair size reduced to 1px for all styles (was 10px).

  QuickSelect (Pro):
  - New: Apply button — apply settings without closing the dialog.
  - New: Mouse buttons MB3, MB4, MB5 can now be bound as the H-key (holster).
  - New: 3 additional action slots (total: 8), accessing wheel positions 7–10.
    Slots 7–10 use mouse movement to select the item while holding Q.
  - New: "Wheel equip" delay — configurable post-Q delay (default 300ms) so the
    item is fully in hand before use. Adjust if your item isn't used completely.

  QuickSave (Pro) — New Feature:
  - New: Automatically drag items between inventory slots and your Safe Pocket.
    One keypress: open inventory → drag item to pocket (or reverse) → close inventory.
  - 5 independent presets, each with: trigger key, source slot (1–8 or Pocket 1–3),
    destination slot (1–8 or Pocket 1–3), and open/close tab toggle.
  - Toggle mode (⇄): activate per preset — first press = forward drag,
    second press = reverse drag. Useful for storing and retrieving the same item.
  - All timing values configurable (open delay, hover, drag hold, drop delay, cooldown).
  - Numpad / toggles QuickSave on/off globally with a toast notification.
  - Configure under Settings → QuickSave... [PRO]

  QuickSelect (Pro):
  - Adjusted: Default LMB timers increased by 150ms across the board.
    T1 1150→1300ms, T2 1650→1800ms, T3 2150→2300ms, T4 4150→4300ms, T5 5150→5300ms.
    If you have saved values, update them manually in QuickSelect settings.

  Bug fixes:
  - Fixed: Profile 1 vibrance (and other settings) were reset to hardware default
    on every EXE restart, regardless of what was saved in the profile.
    Profiles 2–9 were not affected. (Reported by GitHub user — thank you!)
  - Fixed: QuickSave cursor drift — cursor position is now locked every ~8ms during
    hover and drop phases. Mouse movement no longer shifts the item to the wrong slot.
  - Fixed: Arc Raiders center dot renamed from "-1px offset" to "Arc Raiders center dot (2x2px)".
    Visual gap between arms and center block is gone — arms now connect directly to the 2x2 block.
  - Fixed: Map Scanner — Riven Tides could be misidentified as Damm during Night events.
    Detection now uses a ratio score (valid reads / total points) so a 2-point map with
    1 hit (50%) correctly beats a 4-point map with 1 hit (25%).


[ V9.5 ]

  QuickSelect (Pro):
  - New: Press a configurable key to automatically use an item from your
    quick-use wheel — no manual wheel-opening or clicks needed.
    Sequence: hold Q → press slot key → release Q → hold LMB → press H to free hand.
  - 5 independent action slots, each with its own trigger key, wheel slot,
    LMB hold duration, and optional H-key (holster) toggle.
  - Slot names are freely editable — label each slot with the item name.
    Default setup: Slot 1 = Bandage (key D4 / T2, wheel pos 3), Slot 2 = Shield Charger (key D5 / T3, wheel pos 4),
    Slot 3 = Adrenalin (key D6 / T1, wheel pos 5).
  - 6 configurable LMB timers (T1–T6) with item presets:
    T1 Adrenalin Syringe (1150ms), T2 Herb Bandage/Bandage (1650ms),
    T3 Shield Charger (2150ms), T4 Vita Syringe (4150ms),
    T5 Instant Shield Charger (5150ms), T6 custom (1000ms default).
  - Q-key and H-key freely rebindable in dialog.
    Q-Hold duration configurable (50–2000ms, default 200ms).
  - Toggle key (default Numpad Minus / Pos1) pauses/resumes QuickSelect
    with a toast notification.
  - QuickSelect is now enabled by default.
  - Configure under Settings → QuickSelect... [PRO]

  Map Scanner (Pro):
  - Fixed: 4:3 resolutions (e.g. 1920×1440) now work correctly.
    The game renders in a letterboxed 16:9 area on 4:3 screens — OCR regions
    are now offset accordingly. (Thanks @ggvelloso for the report!)

  Autorun:
  - Fixed: pressing W while autorun is active now stops the injection
    but does NOT release W from the game. Character keeps running/sprinting
    until you physically release W yourself.

  Performance:
  - Reduced CPU usage during rapid profile switching. Tray icons for all 9
    profiles are now pre-rendered at startup instead of redrawn on every switch.

  Security:
  - Improved license verification.
  - License file is now stored in AppData\Roaming\BrightRaider\ (clean, visible path).
    Note: V9.3/V9.4 users need to re-enter their license key once after updating.

  General:
  - Toast notifications now appear slightly closer to the taskbar.
  - Config is now stored in AppData\Roaming\BrightRaider\ (visible folder).
    Config from older versions is migrated automatically.


[ V9.4 ]

  Break Reminder (Free):
  - New: Configurable break reminder — shows an orange toast after a set interval
    Default: every 45 minutes. Configure under Settings → Break Reminder.
    Does not steal focus or interrupt gameplay.

  Evac Alarm (Pro):
  - New: Alert when an evac timer drops below a configurable threshold
    Set threshold in minutes + seconds (e.g. 2 min 30 sec)
    Red toast + sound when threshold is crossed. Resets automatically on re-scan.
    Configure inside Settings → Map Scanner → Settings (Evac Alarm section)

  General:
  - Version number now shown in the Exit menu item
  - Toast notifications no longer steal focus while a game is in the foreground
  - Seamless upgrade: V9.3 license is automatically migrated — no re-activation needed
  - Reduced antivirus false positives: removed obfuscation layer that triggered
    packer heuristics. Some detections will always remain — BrightRaider uses a
    low-level keyboard hook and screen capture, the same APIs malware uses.
    Without a code signing certificate (~$150/year) a small number of AV engines
    will always flag tools like this. V9.3 was downloaded 1,400+ times — if
    something were wrong, the internet would know.


[ V9.3 ]

  Autorun (Pro):
  - New: Sprint Mode — autorun can now start directly in sprint.
    Enable under Settings → Autorun → Mode: Sprint.
    Press Shift while autorunning to toggle between walk and sprint on the fly.
  - New: Tap Mode — hold CapsLock for 600ms instead of a short press.
    BrightRaider taps W briefly, pauses, taps again — instead of holding it.
    Built for the Looting Mk. 3 (Survivor) augment: health regenerates to 75%
    while stationary. The pause between taps gives the augment time to regen.
    Your health stays near 75% while you keep moving.
    Adjust timing under Settings → Autorun → Tap Interval...
  - Fixed: C key (slide) now always works correctly during autorun
  - Fixed: Holding CapsLock for Tap Mode no longer accidentally toggles CapsLock
  - Fixed: Settings dialogs now open on the correct screen (multi-monitor setups)

  Calibration Wizard (Pro):
  - Fixed: wizard window no longer appears in the center of the screen during calibration
    Previously the window itself was captured and influenced the brightness measurement.
    It now opens at the bottom of the screen, fully outside all 5 measurement zones.
    Thanks to @KaerPaiku for the report.

  Security:
  - License system updated. A one-time re-activation is required:
    enter your key when prompted after updating.

  General:
  - Crosshair default color is now white


[ V9.2 ]

  Autorun (Pro):
  - New: Press CapsLock to start autorun — character walks forward automatically
  - Shift toggles sprint while autorunning (hold forward + sprint simultaneously)
  - W, S or C cancels autorun; C triggers a slide first (forward momentum)
  - Rebind the autorun key: Settings → Autorun [CapsLock]...

  Audio Ducking (Pro):
  - New: Hold Numpad 0 (Arrow version: hold ↑) for 600ms to duck game audio
  - Game volume drops to configurable percentage (default: 20%)
  - Short press (under 600ms) still mutes/unmutes as before
  - Configure duck volume and hold duration: Settings → Audio Ducking: 20%...

[ V9 ]

  Map Scanner (Pro):
  - New: Hold M on the map to scan all evacuation timers automatically
  - Zooms out, reads all evac points via OCR, starts countdown overlay
  - Supports 5 maps: Buried City, Stella Montis, Space Port, Blue Gate, Damm
  - Color-coded countdown: green (>10 min), yellow (>5 min), orange (>1 min), red (<1 min), gray (closed)
  - Auto-calculates missing timers when one point is partially obstructed
  - Adjustable hold duration (how long to press M) in Map Scanner settings
  - Overlay position: 6 screen positions to choose from
  - Customizable overlay color and font size with live preview
  - Powered by Windows built-in OCR — takes a screenshot, reads timers from it (no game files or memory touched)
  - Works on any resolution (auto-scales from 1080p baseline)

  Update Check:
  - Now checks once on startup and once every 24 hours while the app is running
  - Users who never restart their PC will now see update notifications too

  Timer Overlay:
  - Toggle timer overlay on/off: Numpad* (Numpad version) / Delete/Entf (Arrow version)
  - Toast notification when toggling (consistent with other toggles)

  Arrow Keys Edition:
  - Arrow version now also includes Map Scanner (previously unchanged from V8.1)
  - Hold M on map to scan timers (same as Numpad version)
  - Delete/Entf to toggle the timer overlay on/off

  Auto-Brightness (Pro):
  - New: Configurable zone weights — Settings → Zones...
  - Set how much each of the 5 measurement zones influences the brightness reading (0–10)
  - Default: Center weighted 2x, corners 1x each
  - Useful when HUD elements cover certain zones — set those to 0 to ignore them

  Crosshair Fixes:
  - Fixed: Crosshair now pixel-perfectly centered on all resolutions
  - Fixed: Changing style or size in settings no longer reverts to previous values
