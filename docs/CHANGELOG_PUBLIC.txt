[ V1.1.0 ]

  New in V1.1:
  - Map Scanner now works with other games via downloadable data packs —
    drop a game's pack into the packs folder and its maps, timers and
    conditions are read the same way as Arc Raiders. (See the pack authoring
    guide.)
  - Map Scanner recognises more Arc Raiders map conditions, including
    Uncovered Caches and Hidden Bunker (Spaceport). Hidden Bunker also
    reduces the active evac points and marks the closed hatches.
  - Per-game Auto-HDR: turn Windows HDR on automatically when a chosen game
    launches, off again when it closes. Opt-in per game; Alt-Tabbing in and
    out never flips HDR — it only switches on real game start/exit.
  - New "Movement" tab: Autorun now lives in its own tab, separate from the
    general hotkeys.
  - QuickSave can now swap items to and from your backpack slots, not just
    the Safe Pocket (Backpack 1-4).
  - QuickSelect wheel: pick the target slot from a simple "Slot 1-10"
    dropdown instead of typing a number.
  - Arc Raiders features are now an optional module. A fresh install starts
    as a pure display / FPS tool; enable the Arc Raiders module in the setup
    wizard (or Settings -> App) to add the map scanner, QuickSelect,
    QuickSave and Autorun helpers. Existing users keep it on. Free stays
    free; Pro is unchanged.

  - "Deactivate on this device" (Settings -> App, License): frees your
    license's activation slot for this PC in one click, so you can move to
    a new machine yourself — no support ticket needed.
  - Color-conflict warning: if another tool that controls your display
    colors is running (f.lux, Iris, Windows Night Light, ...), BrightRaider
    now tells you at startup and on the Display tab. Those tools and
    BrightRaider fight over the same gamma pipeline — this was the most
    common cause of "my colors keep reverting".

  Small fixes & polish:
  - Notifications are now color-coded: green = good news (update
    available), yellow = warning, red = risky mode active.
  - Option to mute the QuickSelect / QuickSave confirmation toasts
    (Settings -> App).
  - The "Hotkeys enabled" toggle now stays in sync everywhere the moment you
    change it.
  - The global hotkey-toggle binding is shown on the App tab.
  - Cleaner QuickSave slot list (dropped the redundant "#" column).
  - Many under-the-hood reliability fixes from three rounds of code review:
    safer restore of your FPS limit and display calibration on exit, macro
    timing that no longer trips over Windows clock changes, and various race
    fixes in hotkey handling, the evac countdown and startup/shutdown.

  Everything from V1.0 carries over — settings, profiles and license are
  kept, no re-activation needed for this update.


[ V1.0.0 ]

  The V1.0 release. Major rewrite on .NET 9 + Native AOT + Avalonia UI.
  One EXE, no installer, no .NET runtime required.

  Upgrade note for V9.x users:
  - Settings, profiles, hotkeys, and game profiles migrate automatically
    on first launch.
  - License key must be re-entered once (Settings -> App -> Enter license).
    Lemon Squeezy re-issues the activation instantly — same email, same
    key, no re-purchase. V1.x updates after this won't require another
    re-entry.

  New in V1.0:
  - Map Scanner (Pro): long-press M -> on-screen overlay with live evac
    timers, map + event auto-detection, color-coded warnings, audible
    alarm at configurable threshold.
  - Auto-Brightness (Pro): per-profile brightness ranges, 5-zone screen
    sampling, smooth Gamma/Contrast/Vibrance interpolation. Includes a
    Calibration Wizard.
  - Footstep Booster / Loudness Limiter: per-process audio compressor —
    cap the game's audio session at a threshold so you can crank in-game
    volume to make footsteps audible without going deaf on gunshots.
  - Background mute: auto-mute the game's audio session when Alt-Tab'd
    out, restore on focus return.
  - Process Optimizer: opt-in High priority + physical-cores-only affinity
    for the foreground game.
  - Alt-Tab Auto-Switch: per-game color profile + FPS limit + crosshair
    state, applied in one GPU call (no double-push / no AMD gamma-stuck).
  - Update notifier in the tray menu.
  - Per-profile tray icon color, ●-marker for active profile.
  - Configurable hotkeys (no more separate Arrow EXE).
  - Resizable Settings window with sidebar tabstrip; dark mode.

  Free features stay free. Pro adds Auto-Brightness, Map Scanner,
  QuickSelect, QuickSave, Footstep Booster.

  Bug fixes vs V9.6.1:
  - Original gamma ramp is saved to disk on first launch and reloaded
    every startup. A crashed or force-killed BrightRaider can never
    poison the saved baseline — your DisplayCAL / ICC calibration is
    safe across any crash.
  - New App-tab buttons: "Reset to neutral now" pushes a known-clean
    gamma immediately. "Re-capture original gamma" updates the saved
    baseline to the current state (use after recalibrating).
  - Config saves are atomic (.tmp + replace + .bak fallback) — no more
    corrupted config on power loss / crash.
  - Single-instance lock — second launch raises the existing window
    instead of running two copies.
  - Break reminder now respects the live toggle — turning it off in
    Settings stops the timer immediately (was: needed app restart).
  - Calibration Wizard: buttons readable on dark theme, live value
    updates immediately, Enter reliably confirms each step.
  - Auto-Brightness respects the global On/Off hotkey (was: kept
    pushing gamma even when BrightRaider was supposedly off).
  - Tray toggles and Settings dialog stay in sync — toggling Alt-Tab
    or Auto-Brightness via the tray no longer gets clobbered when the
    Settings dialog is open.
  - Settings window remembers its size between launches.
  - Modifier-key bindings (Ctrl+, Alt+, Shift+ combinations) are
    fully supported and documented inline in the binding tabs.

  Pre-release updates (shaped by tester feedback — thanks @DBasic,
  @Tia-Nastacia and @dawuus):

  New in this window:
  - HDR toggle hotkey (Free): flip Windows HDR on/off with one key
    instead of digging through Windows Settings. Pinned-monitor aware,
    unbound by default; your color profile is re-applied after the mode
    switch.
  - Audio Output Switcher (Pro): switch the default output device
    (speakers <-> headphones, or cycle any set you choose) with one
    hotkey. Optional auto-switch to a chosen device when a game starts,
    restoring the previous one when it closes (Alt-Tab does NOT switch
    back). Moves the game/media device only by default; an opt-in "Also
    switch the communications device" makes Discord/voice follow too
    (off by default so voice apps like TeamSpeak aren't disrupted).
  - "Apps to ignore" list (Game Profiles tab): fullscreen windows that
    aren't games (browser video, media players) are left completely
    alone -- no overlays, no color change, no FPS cap. Common browsers
    and players are excluded out of the box.
  - "Only run hotkeys while a game is focused": optional gate so
    BrightRaider's keys never interfere with desktop typing.

  QuickSelect / QuickSave rework:
  - QuickSelect: per-slot LMB hold time typed directly in ms (the old
    T1-T6 preset table is gone), five common heals pre-filled, a Timing
    reference button, and the post-use action correctly labeled Holster.
    Wheel slots 3-6 are selected by their in-game number key (immune to
    mouse movement); 7-10 use the cursor.
  - QuickSave: From/To are plain dropdowns named like the in-game
    inventory (Slot 1-5 / Augment 1-3 / W1-W2 / P1-P3); the trigger
    toast reads e.g. "W1 -> P1" (or "W1 <-> P1" for toggle presets). An
    in-app hint explains the timing (Drop hold is the key setting).
  - Both tabs: a "Slot layout" button shows the annotated in-game
    loadout and a "Guide" button opens the full guide. Existing presets
    and timings migrate automatically.

  Display & overlays:
  - Brightness profiles match the V9.6.1 look again; "Brighter" is
    usable.
  - Nvidia Hue runs 0-359 like the Control Panel (was a centered
    -180..+180). Range still adapts to your GPU.
  - Overlays (crosshair, map scanner, timers) stay on the monitor you
    pin, and anchor to the game's monitor on "All Monitors" instead of
    chasing whatever window you click; vibrance/hue apply to the pinned
    monitor only.
  - Pinned-monitor startup fix (vibrance no longer flashes on all
    monitors at launch); a monitor plugged in after launch restores its
    original gamma on exit / Alt-Tab.

  Input & hotkeys:
  - No input freeze on Alt-Tab and no "stuck" mouse button -- the
    keyboard/mouse hooks run on their own thread; the held-click macro
    path was hardened too.
  - Fixed a system-wide stuck Shift with Autorun running (symmetric
    swallow so key-repeat can't latch Shift).
  - Modifier + mouse bindings work (e.g. "Ctrl + Wheel up", "Shift+MB4").
  - Global On/Off key is swallowed on every edge and no longer leaks to
    the game or other apps.
  - While a rebind field is waiting, hotkeys/macros pause so the key you
    press is captured cleanly instead of firing.
  - Autorun: crouch (C) is no longer blocked after you take over a
    sprint with W; tapping C now slides and keeps running.
  - Number fields reject letters and other non-numeric input.
  - Crosshair outline thickness is adjustable (1-5), separate from the
    outline color. Every slider takes the mouse wheel and has a type-in
    field; an "Advanced" toggle hides the millisecond-timing fields.

  Map Scanner:
  - Verified 100% accurate across resolutions and aspect ratios
    (16:9, 16:10, ultrawide, 2560x1600, etc.).
  - A map with no condition shows just its name (no redundant "Normal").
  - Evac alarm: plays its own audible tone (independent of your Windows
    sound scheme), optional repeat, color-coded toast, re-arms per evac
    point, and stays silent whenever the scanner overlay is hidden.

  Reliability & polish:
  - Full code-review stability pass across input hooks, audio device
    switching, macro injection and the map scanner.
  - Settings backup now actually recovers a corrupted config instead of
    resetting to defaults.
  - Audio device switch no longer crashes voice apps (game/media only by
    default; rapid presses handled cleanly).
  - License: activation unlocks Pro live (no restart); the saved license
    persists even if the store omits the email.
  - Lower-overhead Auto-Brightness sampling (reuses one GDI surface
    across all five zones); the "Center" zone weight now applies to the
    actual center zone.
  - Sharper app icon at small sizes (Task Manager, Explorer, title bar).
  - Right-click the version line to copy full system info for bug
    reports; the version line flags when an update is available.
  - Fixed: re-running the Setup Wizard from an open Settings window is no
    longer overwritten by the dialog's next Apply.


[ V9.6.1 ] - Previous Version

  Bug fixes:
  - Fixed: Mouse stutter and game input lag while BrightRaider is running.
    Config saves and menu rebuilds were happening on the Windows keyboard hook
    thread, which has a strict ~300ms OS timeout. This stalled the entire input
    system — mouse movement, key presses — especially noticeable on fast GPUs
    and 4K displays. Both operations are now dispatched asynchronously.
  - Fixed: Auto-Brightness caused unnecessary GPU wake-ups on every tick
    (every second). BrightRaider now skips the GPU call when brightness/contrast
    hasn't changed. Fixes micro-stutter on Optimus laptops (NVIDIA dGPU + iGPU).


[ V9.6 ]

  Map Scanner (Pro):
  - New: Riven Tides map added — Coastal Lift and Customs Lift.
  - New: Night, Hurricane, and Electromagnetic Storm event detection.
    The overlay shows the active event name next to the map name.
    Evac points are automatically adjusted per event type:
    Night → 2 active points, Electromagnetic Storm → 3, Hurricane → all standard.
    Excess points are shown as CLOSED immediately, without waiting for a timer scan.
  - New: "⚠ Raider Hatches closed" warning shown during Night and Storm events.

  Crosshair:
  - New: Outline option for all crosshair styles — configurable outline color,
    improves visibility on bright backgrounds.
  - New: Outline rendering rewritten (Cross, CrossGap, TShape) — now pixel-perfect
    and symmetric at all sizes. Fixes the left-side misalignment visible at small sizes.
  - New styles: Ring (circle only) and Cross-with-gap (CS:GO-style with adjustable gap size).
  - Fixed: Cross-with-gap disappeared below 6px. Also fixed: sizes 6 and 7 looked identical.
    Arms are now visible at any size.
  - Fixed: Dot crosshair is now a circle, fully adjustable via the size slider
    (was previously fixed at 7×7px regardless of slider position).
  - Minimum crosshair size reduced to 1px for all styles (was 10px).

  QuickSelect (Pro):
  - New: Apply button — apply settings without closing the dialog.
  - New: Mouse buttons MB3, MB4, MB5 can now be bound as the H-key (holster).
  - New: 3 additional action slots (total: 8), accessing wheel positions 7–10.
    Slots 7–10 use mouse movement to select the item while holding Q.
  - New: "Wheel equip" delay — configurable post-Q delay (default 300ms) so the
    item is fully in hand before use. Adjust if your item isn't used completely.

  QuickSave (Pro) — New Feature:
  - New: Automatically drag items between inventory slots and your Safe Pocket.
    One keypress: open inventory → drag item to pocket (or reverse) → close inventory.
  - 5 independent presets, each with: trigger key, source slot (1–8 or Pocket 1–3),
    destination slot (1–8 or Pocket 1–3), and open/close tab toggle.
  - Toggle mode (⇄): activate per preset — first press = forward drag,
    second press = reverse drag. Useful for storing and retrieving the same item.
  - All timing values configurable (open delay, hover, drag hold, drop delay, cooldown).
  - Numpad / toggles QuickSave on/off globally with a toast notification.
  - Configure under Settings → QuickSave... [PRO]

  QuickSelect (Pro):
  - Adjusted: Default LMB timers increased by 150ms across the board.
    T1 1150→1300ms, T2 1650→1800ms, T3 2150→2300ms, T4 4150→4300ms, T5 5150→5300ms.
    If you have saved values, update them manually in QuickSelect settings.

  Autorun:
  - New: AZERTY keyboard support — enable "AZERTY keyboard (Z = forward)" in the Autorun menu
    to use Z as the forward key instead of W. For French keyboard layouts.

  Bug fixes:
  - Fixed: Profile 1 vibrance (and other settings) were reset to hardware default
    on every EXE restart, regardless of what was saved in the profile.
    Profiles 2–9 were not affected. (Reported by GitHub user — thank you!)
  - Fixed: QuickSave cursor drift — cursor position is now locked every ~8ms during
    hover and drop phases. Mouse movement no longer shifts the item to the wrong slot.
  - Fixed: Arc Raiders center dot renamed from "-1px offset" to "Arc Raiders center dot (2x2px)".
    Visual gap between arms and center block is gone — arms now connect directly to the 2x2 block.
  - Fixed: Map Scanner — Riven Tides could be misidentified as Damm during Night events.
    Detection now uses a ratio score (valid reads / total points) so a 2-point map with
    1 hit (50%) correctly beats a 4-point map with 1 hit (25%).
  - Fixed: QuickSelect slots 7 & 8 cursor position wrong on non-1080p resolutions.
    Wheel slot positions are now scaled to actual screen resolution.
    Previously the cursor landed at the wrong position on 1440p, 4K and ultrawide screens.
    (Reported by GitHub user — thank you!)
  - Fixed: Crosshair color picker — picking a color from the "Basic colors" panel resulted
    in a transparent crosshair (alpha 0). Color now always uses full opacity.
  - Fixed: License incorrectly reset to Free when the validation server was unreachable
    (no internet, timeout, firewall). License is now only revoked when the server explicitly
    responds that the key is invalid.
  - Fixed: First launch toast notification briefly stole focus from the game window.

  General:
  - Version number now shown in the Exit menu item
  - Toast notifications no longer steal focus while a game is in the foreground
  - Seamless upgrade: V9.3 license is automatically migrated — no re-activation needed

    something were wrong, the internet would know.
