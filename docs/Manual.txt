WHAT IS BRIGHTRAIDER?
  BrightRaider is a lightweight Windows tray tool that lets you
  instantly switch between display profiles using hotkeys. Each
  profile changes gamma, contrast, and digital vibrance/saturation
  - perfect for gaming (especially Arc Raiders!), or quickly
  boosting visibility in dark scenes.

  The tool auto-detects your GPU (NVIDIA or AMD) and uses the
  correct driver API automatically. On systems without a
  supported GPU, gamma and contrast still work via Windows API.

  The app runs silently in your system tray and uses almost
  no resources. No installation required.

  One EXE — hotkeys are fully configurable. A Setup Wizard
  picks sensible defaults on first launch (Numpad, TKL, AZERTY).

  - Auto-detects GPU - no configuration needed

  - Per-monitor control (choose one or all monitors)

FIRST LAUNCH - IMPORTANT
  On first launch, BrightRaider needs to make a small, safe
  change to your Windows registry. Here is exactly what
  happens and why:

  1. You double-click BrightRaider.exe
  2. Windows shows a UAC prompt ("Do you want to allow
     this app to make changes?") - click YES
  3. This creates ONE registry entry:

     Location: HKLM\SOFTWARE\Microsoft\Windows NT\
               CurrentVersion\ICM
     Name:     GdiIcmGammaRange
     Value:    256

     WHAT DOES THIS DO?
     Windows has a built-in restriction that blocks apps
     from adjusting display gamma. This registry entry
     simply tells Windows: "Allow gamma adjustments."
     It does NOT change any display settings itself.
     It does NOT affect system stability or security.
     It is used by many display calibration tools.
     It can be safely removed at any time.

  4. RESTART YOUR PC (only needed once!)
  5. Start BrightRaider.exe again - done!

  The UAC prompt only appears ONCE. After that, the app
  runs without any admin rights.

MODIFIER BINDINGS (Ctrl / Alt / Shift)
  Every rebindable field accepts modifier + key combinations:
    1. Click the field (it shows "Press a key...")
    2. Hold Ctrl, Alt, and/or Shift
    3. Press the trigger key — e.g. Shift+5, Ctrl+Numpad 5, Alt+F2
    4. Esc cancels the rebind without changing anything

  Bindable: A-Z, 0-9, F1-F24, Numpad keys, OEM punctuation,
            arrow + nav keys, Mouse MB3/MB4/MB5, Wheel up/down.

  NOT bindable on their own (modifier-only): Shift, Ctrl, Alt, Win,
            left/right modifier variants, Esc, Tab, Enter — these
            are reserved for UI navigation and modifier chording.

  OS-reserved combos (you can bind them, but Windows will eat them
  before BrightRaider sees the press): Win+L, Win+D, Win+E, Win+R,
  Win+S, Win+I, Win+Tab, Alt+F4, Alt+Tab, Ctrl+Alt+Del,
  Ctrl+Shift+Esc. BrightRaider shows a warning toast in these cases.

  Sprint conflict: if you bind anything with Shift+ while Sprint is
  bound to Shift, the binding will fire every time you sprint in-game.
  A warning toast appears. Either:
    - pick Ctrl+ or Alt+ instead, or
    - rebind Sprint to a non-Shift key (Hotkeys tab -> Sprint key).

AUTORUN (Pro)
  Press CapsLock briefly to start autorunning. BrightRaider holds W for you
  so your character walks (or sprints) forward automatically.

  While autorunning:
    CapsLock again  ->  Stop autorun
    Shift           ->  Toggle sprint (press again to go back to walk)
    W               ->  Stops injection — character keeps running until you release W
    S               ->  Cancel autorun fully, key passes through to game
    C               ->  Slide first (while still moving forward), then stop

  Sprint Mode: Settings -> Autorun -> Mode: Sprint
    Autorun starts in sprint immediately instead of walking.

  TAP MODE — hold CapsLock for 600ms:
    Instead of holding W continuously, BrightRaider pulses W at timed intervals.
    W is pressed briefly (default: 169ms), then released (default: 990ms pause).

    Built for the Looting Mk. 3 (Survivor) augment:
    The augment regenerates health up to 75% while downed and stationary.
    During the 990ms pause your character is stationary — health regens.
    The brief W tap keeps you moving. Result: health stays near 75%.

    Configure: Settings -> Autorun -> Tap Interval...
      - W press duration (ms) — how long W is held per tap
      - Pause between taps (ms) — stationary time between taps
      Enter exact millisecond values.

  AZERTY keyboard support:
    Enable "AZERTY keyboard (Z = forward)" in Settings -> Autorun to use Z as
    the forward key instead of W. For French keyboard layouts.

  Rebind the autorun key: right-click tray -> Settings -> Autorun [CapsLock]...
  Press any key to rebind, Esc to cancel.

AUDIO DUCKING (Pro)
  The mute key (Numpad 0 / Arrow Up) has two modes:

    Short press (under hold duration)  ->  Mute/unmute game audio
    Hold (default: 600ms)              ->  Duck game audio to configured volume

  Ducking reduces game volume to a set percentage (default: 20%) so you can
  hear Discord or music without fully muting the game. Hold again to restore.

  Configure: right-click tray -> Settings -> Audio Ducking: 20%...
    - Volume: 0-100% (how loud the game is while ducked)
    - Hold duration: 200-2000ms (how long to hold before ducking triggers)

FOOTSTEP BOOSTER / LOUDNESS LIMITER (Pro) — NEW in V1.0
  Caps the game's audio session at a configurable threshold so you can
  crank in-game volume to make footsteps audible without going deaf on
  gunshots. Per-process — only the configured game gets limited; Discord,
  music, browser stay untouched.

  Configure: Settings -> Audio -> Footstep Booster
    - Threshold (10-90 %): volume level above which the limiter kicks in.
      Lower = more aggressive compression. Start around 35-45 %.
    - Attack (1-200 ms): how fast the limiter pulls volume down on a loud
      transient. Lower = catches sharp gunshots; too low = audible clicks.
      Start around 10-20 ms.
    - Release (50-2000 ms): how fast volume returns to baseline after the
      loud sound passes. Higher = smoother but slower to hear footsteps
      again. Start around 250-400 ms.

  See FootstepBooster_Guide.md for detailed tuning steps.

BACKGROUND MUTE (Pro) — NEW in V1.0
  Auto-mute the game's Windows audio session when Alt-Tab'd out, unmute
  on focus return. Quiets the game while you browse, watch a video or
  check Discord. Per-process — your music + Discord keep playing.

  Configure: Settings -> Audio -> "Auto-mute game when Alt-Tab'd out"

QUICKSELECT (Pro)
  Press a single key to automatically use an item from your quick-use wheel.
  BrightRaider handles the entire sequence:
    1. Hold Q (wheel opens)
    2. Press your slot key (item selected)
    3. Release Q (item goes to hand)
    4. Hold Left Mouse Button for the configured duration (item used)
    5. Press H (holster / free hand) — optional, per slot

  Default trigger keys: 4, 5, 6 (keys above the letter row, not numpad)
  The keys are intercepted while QuickSelect is active — the game does NOT
  receive them directly (Q handles the slot selection internally).

  SETUP:
    1. Right-click tray -> Settings -> QuickSelect... [PRO]
    2. Check "Enable QuickSelect"
    3. Click a bind button and press your desired trigger key for each slot
    4. Set the wheel slot number (1-9, matching your in-game slot assignment)
    5. Choose an LMB timer matching your item type (see presets below)
    6. Enable H-key per slot if you want the hand freed after use
    7. Click OK

  LMB TIMER PRESETS (how long Left Mouse Button is held):
    T1  1150ms  —  Adrenalin Syringe
    T2  1650ms  —  Herb Bandage / Bandage
    T3  2150ms  —  Shield Charger
    T4  4150ms  —  Vita Syringe
    T5  5150ms  —  Instant Shield Charger
    T6  custom  —  set your own value (default 1000ms, max 8000ms)

  CONFIGURATION OPTIONS:
    Toggle Key     — pause/resume QuickSelect (default: Numpad Minus)
    Q-Key          — the key that opens your quick-use wheel (default: Q)
    H-Key          — the key that frees your hand after use (default: H)
    Q-Hold         — how long Q is held before slot selection (50-2000ms)
    Active (✓)     — enable/disable each slot individually
    Trigger key    — the key you press to trigger this slot
    Slot           — which wheel slot to select (1-9)
    Timer          — which LMB duration preset to use for this slot
    H              — whether to press H after item use for this slot

  TIPS:
    - Test with a low-value item first before using in-game.
    - If the item is only partially used, increase the LMB timer (T+1 or T+2).
    - If the wheel closes too fast, increase Q-Hold by 50ms increments.
    - Toggle QuickSelect off (toggle key) when typing in chat to avoid
      accidentally triggering slots.
    - The Arrow version uses Pos1 (Home) as the toggle key by default.
    - Slots 7–8 use mouse movement: Q is held, cursor moves to the wheel
      position, Q is released. No key press needed for slot selection.
    - H-Key can be bound to MB3, MB4, or MB5 in addition to keyboard keys.
    - Apply button saves settings without closing the dialog.
    - After pressing H to cancel an item mid-use, wait a moment before
      triggering QuickSelect again. The game keeps the item in a transitional
      state briefly — retriggering immediately will pull the item out without
      using it. This is game-side behavior.

QUICKSAVE (Pro)
  QuickSave automatically drags items between your inventory and your Safe Pocket
  with a single keypress or mouse-wheel scroll — no manual clicking required.

  WHAT YOU CAN MOVE:
    - Any item in inventory slots 1–8 (this includes all QuickSelect slots
      and any weapon you have equipped in your quick-use wheel)
    - Items in Safe Pocket slots 1–3
    - Direction is fully configurable: slot → pocket or pocket → slot

  HOW IT WORKS:
    1. You press the assigned hotkey (or scroll the mouse wheel)
    2. BrightRaider opens your inventory (Tab)
    3. Moves the cursor to the source slot
    4. Holds Left Mouse Button and drags to the destination slot
    5. Releases Left Mouse Button
    6. Closes inventory (Tab)

  SETUP:
    1. Right-click tray → Settings → QuickSave... [PRO]
    2. Check "On" for the preset you want to configure
    3. Click the key button and press your trigger key (keyboard, MB3/4/5, or Wheel↑/↓)
    4. Set "From" — the source slot (Slot 1–8 or Pocket 1–3)
    5. Set "To" — the destination slot (Slot 1–8 or Pocket 1–3)
    6. Enable "Open" and "Close" to have BrightRaider open/close inventory automatically
    7. Click Apply or OK

  TOGGLE DIRECTION (⇄):
    Enable per preset. First trigger press moves From→To, second press moves To→From.
    Useful for storing a snap hook: one press puts it in the pocket, next press takes it out.

  TIMING (configure if drag fails):
    Open  — how long to wait after Tab before moving the cursor (default 250ms)
    Hover — extra wait after cursor arrives at source (default 0ms)
    Hold  — how long LMB is held while dragging (default 0ms)
    Drop  — wait before releasing LMB at destination (default 120ms)
    Cooldown — minimum time between two triggers (default 0ms, disabled)

  TOGGLE ON/OFF:
    Numpad /  →  Toggle QuickSave on/off  (Numpad version)
    End       →  Toggle QuickSave on/off  (Arrow version)
    Toast confirms. Configure tab key: Settings → QuickSave → Tab Key bind button

  KNOWN LIMITATION:
    Occasional drag failures can occur. This is a known behavior of the
    Unreal Engine Slate UI system used by Arc Raiders — the same thing
    happens with normal manual drag-and-drop in the inventory.
    It cannot be fixed from outside the game. If it happens, just trigger again.

AUTO-BRIGHTNESS (Pro)
  When enabled, BrightRaider analyzes 5 zones on your screen
  (center weighted, 4 corners) using median brightness. Based
  on the result, it smoothly switches between profiles.
  Dark screen = more boost, bright screen = less.

  Enable via: Tray Menu -> Auto-Brightness (Screen Analysis)
  Calibrate: two steps — measure darkest spot, measure brightest.
  The calibration window appears at the bottom of the screen,
  outside all 5 measurement zones — so it does not skew results.

  Zone Weights: Tray Menu -> Settings -> Zones...
    Each of the 5 zones (Center, Top Left, Top Right, Bottom Left, Bottom Right)
    has a weight from 0 to 10. Higher = more influence on the result.
    Set a zone to 0 to ignore it entirely (useful when HUD elements cover a corner).
    Default: Center=2, all corners=1.

  See AutoBrightness_Guide.md for the full calibration walkthrough.

ALT-TAB AUTO-SWITCH (Free) — NEW in V1.0
  Per-game profile + FPS limit + crosshair, applied automatically when
  a configured game enters the foreground. No more switching profiles
  by hand or running VibranceGUI alongside.

  How it works:
    1. Add a game in Settings -> Game Profiles -> "Add..."
    2. Pick a base profile (overrides optional: own Gamma/Contrast/
       Vibrance/Hue/FPS-limit for this game only)
    3. Launch the game — BrightRaider detects it, applies the profile,
       enables the crosshair (if configured), sets the FPS limit
    4. Alt-Tab out — original ramps + vibrance + hue restored, crosshair
       hidden. Tab back in — game profile re-applied
    5. Other games NOT in your list get neutral display state

  FPS Limit per game:
    - NVIDIA: NvAPI DRS (Driver Settings) — clean, no DirectX hook
    - AMD: ADLX FRTC via amdadlx64.dll
    - Intel: no public API — UI shows a note
    - Power saving + lower fan noise: GPU stops rendering frames the
      monitor can't display.

PROCESS OPTIMIZER (Pro, opt-in) — NEW in V1.0
  When a foreground game is detected, BrightRaider can boost its
  Windows process priority and pin it to physical CPU cores only
  (Hyperthreading off). Smoother frametimes on cores fighting with
  background tasks.

  Configure: Settings -> Performance
    - "Run game as High priority" — Windows ProcessPriorityClass.High
    - "Disable Hyperthreading (physical cores only)" — pins affinity
      to cores 0, 2, 4, ... (skips SMT siblings)

  Opt-in — both off by default. Reverts to Normal priority + full
  affinity when you Alt-Tab out or close the game.

HOTKEY PAUSE (Pro)
  Temporarily disables all BrightRaider hotkeys. The app keeps
  running — it just stops intercepting key presses.

  Toggle via: right-click tray -> Settings -> Pause Hotkeys
  A toast confirms when hotkeys are paused or resumed.

GLOBAL ON/OFF (Numpad Entf — Free)
  Two flavours, picked under Settings -> App ->
  "Toggle OFF also resets the display":

    Checked (default) = FULL OFF
      Hides every overlay (crosshair, map scanner, brightness debug),
      restores your original gamma / vibrance / hue, pauses Auto-
      Brightness, and stops the Footstep Booster. The display behaves
      as if BrightRaider weren't running. Press the toggle again to
      re-apply the active profile.

    Unchecked = HOTKEY PAUSE
      Only the hotkeys are paused. Your active color profile, overlays
      and FPS limit all stay in place. Useful when you just need the
      keys back for chat / another app, without losing your tuned
      display state. Same behaviour V9.x had on Page Down / Numpad Entf.

VIBRANCE RESTORE
  BrightRaider reads your current GPU vibrance on startup and restores
  it when you exit — so your display always returns to its original state.
  Profile 1 keeps whatever value you configured (it is not automatically
  overwritten with the hardware default).

MONITOR SELECTION
  By default, all monitors change together. To change only
  one monitor: right-click the tray icon and select the
  specific display. Your choice is saved automatically.

NOTES
  - Numpad keys are captured while the tool is running.
    Regular number keys (above letters) are NOT affected.
  - Digital Vibrance (NVIDIA) / Saturation (AMD) changes are
    visible in the respective GPU control panel.
    Gamma/Contrast changes are NOT shown there
    (this is normal - they work via a different API).
  - The tray menu shows your detected GPU at the bottom
    (NVIDIA, AMD, or None).
  - If something looks wrong: just exit the app. Everything
    resets to normal automatically.

UNINSTALL
  1. Exit BrightRaider (right-click tray -> Exit)
  2. Delete the folder
  3. Optional: Remove the registry entry:
     HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ICM
     -> Delete "GdiIcmGammaRange"
  4. Optional: Remove auto-start entry:
     HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
     -> Delete "BrightRaider"

  per Tastendruck zwischen Display-Profilen wechseln kannst.

  Saettigung gleichzeitig - perfekt fuer Gaming (besonders

  und nutzt die richtige Treiber-API. Auf Systemen ohne
  unterstuetzte GPU funktionieren Gamma und Kontrast trotzdem
  ueber die Windows-API.

ERSTER START - WICHTIG
  Beim ersten Start muss BrightRaider eine kleine, sichere
  Aenderung in der Windows-Registry vornehmen. Hier ist genau
  erklaert was passiert und warum:

  1. Du doppelklickst BrightRaider.exe
  2. Windows zeigt eine UAC-Abfrage ("Moechten Sie zulassen,
     dass diese App Aenderungen vornimmt?") - klicke JA
  3. Es wird EIN Registry-Eintrag erstellt:

     Ort:   HKLM\SOFTWARE\Microsoft\Windows NT\
            CurrentVersion\ICM
     Name:  GdiIcmGammaRange
     Wert:  256

     WAS MACHT DIESER EINTRAG?
     Windows hat eine eingebaute Beschraenkung, die Apps
     daran hindert, die Display-Gamma-Werte zu aendern.
     Dieser Registry-Eintrag sagt Windows einfach:
     "Erlaube Gamma-Anpassungen."
     Er aendert KEINE Bildschirmeinstellungen selbst.
     Er beeinflusst NICHT die Systemstabilitaet.
     Er ist KEIN Sicherheitsrisiko.
     Er wird von vielen Kalibrierungs-Tools verwendet.
     Er kann jederzeit wieder entfernt werden.

  4. PC NEU STARTEN (nur einmalig noetig!)
  5. BrightRaider.exe erneut starten - fertig!

  Die UAC-Abfrage kommt nur EINMAL. Danach laeuft die App
  ohne Admin-Rechte.

MODIFIER-BELEGUNGEN (Strg / Alt / Shift)
  Jedes belegbare Feld akzeptiert Modifier + Taste:
    1. Auf das Feld klicken (zeigt "Taste druecken...")
    2. Strg, Alt und/oder Shift halten
    3. Trigger-Taste druecken — z.B. Shift+5, Strg+Numpad 5, Alt+F2
    4. Esc bricht die Belegung ohne Aenderung ab

  Belegbar: A-Z, 0-9, F1-F24, Numpad-Tasten, OEM-Zeichen,
            Pfeil- und Navigationstasten, Maus MB3/MB4/MB5,

  NICHT belegbar als Einzeltaste (nur als Modifier): Shift, Strg,
            Alt, Win, linke/rechte Modifier-Varianten, Esc, Tab,
            Enter — diese sind fuer UI-Navigation reserviert.

  OS-reservierte Kombinationen (belegbar, aber Windows fängt sie ab
  bevor BrightRaider sie sieht): Win+L, Win+D, Win+E, Win+R, Win+S,
  Win+I, Win+Tab, Alt+F4, Alt+Tab, Strg+Alt+Entf, Strg+Shift+Esc.
  BrightRaider zeigt in diesen Faellen einen Warn-Toast.

  Sprint-Konflikt: Wenn du Shift+ als Modifier verwendest waehrend
  Sprint auf Shift belegt ist, feuert die Belegung bei jedem Sprint
  im Spiel. Ein Warn-Toast erscheint. Entweder:
    - Strg+ oder Alt+ als Modifier waehlen, oder
    - Sprint umbelegen (Hotkeys-Tab -> Sprint-Taste).

AUTORUN (Pro)
  CapsLock kurz druecken um Autorun zu starten. BrightRaider haelt W fuer
  dich — dein Charakter laeuft (oder rennt) automatisch vorwaerts.

  Waehrend Autorun aktiv:
    CapsLock nochmal  ->  Autorun stoppen
    Shift             ->  Sprint an/aus (nochmal druecken fuer Gehen)
    W                 ->  Stoppt Injektion — Charakter laeuft weiter bis W losgelassen
    S                 ->  Autorun komplett abbrechen, Taste ans Spiel weitergegeben
    C                 ->  Slide ausloesen (waehrend noch Bewegung vorwaerts), dann stoppen

  Sprint-Modus: Einstellungen -> Autorun -> Modus: Sprint
    Autorun startet sofort im Sprint statt im Gehen.

  TAP-MODUS — CapsLock 600ms halten:
    Statt W durchgehend zu halten, wird W in Intervallen getippt.
    W wird kurz gedrueckt (Standard: 169ms), dann losgelassen (Standard: 990ms Pause).

    Gebaut fuer das Looting Mk. 3 (Survivor) Augment:
    Das Augment regeneriert Leben bis 75% waehrend du zu Boden bist und stillstehst.
    In der 990ms Pause steht dein Charakter still — Leben regeneriert.
    Der kurze W-Tipp bewegt dich weiter. Ergebnis: Leben bleibt bei ~75%.

    Konfigurieren: Einstellungen -> Autorun -> Tap-Abstand...
      - W-Haltezeit (ms) — wie lange W pro Tipp gedrueckt bleibt
      - Pause zwischen Tipps (ms) — Stillstandszeit zwischen Tipps
      Exakte Millisekunden-Werte eingebbar.

  AZERTY-Tastatur-Support:
    "AZERTY-Tastatur (Z = vorwaerts)" in Einstellungen -> Autorun aktivieren,
    um Z statt W als Vorwaerts-Taste zu nutzen. Fuer franzoesische Tastaturen.

  Taste neu belegen: Rechtsklick Tray -> Einstellungen -> Autorun [CapsLock]...
  Beliebige Taste druecken zum Belegen, Esc zum Abbrechen.

AUDIO DUCKING (Pro)
  Die Stumm-Taste (Numpad 0 / Pfeil Hoch) hat zwei Modi:

    Kurzer Druck (unter Haltezeit)  ->  Spiel stumm/laut
    Halten (Standard: 600ms)        ->  Spiel-Audio auf eingestellten Prozentsatz reduzieren

  Ducking reduziert die Spiel-Lautstaerke auf einen einstellbaren Prozentsatz
  (Standard: 20%), damit du Discord oder Musik hoerst ohne das Spiel komplett
  zu stummschalten. Nochmals halten stellt die normale Lautstaerke wieder her.

  Konfigurieren: Rechtsklick Tray -> Einstellungen -> Audio Ducking: 20%...
    - Lautstaerke: 0-100% (wie laut das Spiel im gedaempften Zustand ist)
    - Haltezeit: 200-2000ms (wie lange halten bis Ducking ausgeloest wird)

FOOTSTEP BOOSTER / LOUDNESS LIMITER (Pro) — NEU in V1.0
  Begrenzt die Lautstaerke der Spiel-Audio-Session bei einem konfigurier-
  baren Schwellwert. Du kannst die In-Game-Lautstaerke hochdrehen um
  Schritte zu hoeren, ohne dass dir Schuesse das Trommelfell zerlegen.
  Per-Prozess — nur das konfigurierte Spiel wird limitiert; Discord,
  Musik, Browser bleiben unberuehrt.

  Konfigurieren: Einstellungen -> Audio -> Footstep Booster
    - Schwellwert (10-90 %): Lautstaerke ab der der Limiter eingreift.
      Niedriger = staerkere Kompression. Start bei ~35-45 %.
    - Attack (1-200 ms): wie schnell der Limiter bei einem lauten
      Transienten herunterregelt. Niedriger = faengt scharfe Schuesse
      ab; zu niedrig = hoerbare Klicks. Start bei ~10-20 ms.
    - Release (50-2000 ms): wie schnell die Lautstaerke nach dem lauten
      Geraeusch wieder hochfaehrt. Hoeher = sanfter, aber Schritte sind
      langsamer wieder hoerbar. Start bei ~250-400 ms.

  Siehe FootstepBooster_Guide.md fuer detaillierte Tuning-Schritte.

BACKGROUND MUTE (Pro) — NEU in V1.0
  Stummschaltet die Windows-Audio-Session des Spiels automatisch beim
  Alt-Tab raus, hebt die Stummschaltung beim Fokus-Return wieder auf.
  Spiel ist leise waehrend du surfst, ein Video schaust oder Discord
  checkst. Per-Prozess — Musik + Discord laufen weiter.

  Konfigurieren: Einstellungen -> Audio -> "Spiel beim Alt-Tab stumm"

MAP SCANNER (Pro)
  M auf der Karte gedrückt halten. BrightRaider zoomt
  automatisch heraus, scannt alle Evakuierungspunkte per
  Windows-OCR und zeigt einen Live-Countdown auf dem Bildschirm.

  Unterstuetzte Karten:
    Buried City, Stella Montis, Space Port, Blue Gate, Damm, Riven Tides

  Farbkodierung:
    Gruen  = mehr als 10 Minuten
    Gelb   = mehr als 5 Minuten
    Orange = mehr als 1 Minute
    Rot    = weniger als 1 Minute
    Grau   = geschlossen / unbekannt

  Timer-Overlay an/ausschalten:
    Numpad* (Numpad-Version) / Entf (Arrow-Version)
    Ein Toast bestaetigt das Umschalten.

  Event-Erkennung:
    Wenn ein In-Game-Event aktiv ist, erkennt BrightRaider es automatisch
    und passt die Anzahl der angezeigten aktiven Evakuierungspunkte an:
      Nacht                  — 2 aktive Punkte, Warnung "Raider Hatches zu"
      Hurrikan               — alle Punkte aktiv
      Elektromagnetischer Sturm — 3 aktive Punkte, Warnung "Raider Hatches zu"
    Der Event-Name erscheint im Overlay unter dem Kartennamen.

  Konfigurieren: Rechtsklick Tray -> Map Scanner Einstellungen
    - Haltedauer (wie lange M gehalten werden muss)
    - Position des Overlays (6 Optionen)
    - Schriftgroesse und Farbe

QUICKSELECT (Pro)
  Druecke eine Taste um automatisch ein Item aus dem Schnellradzusatz zu benutzen.
  BrightRaider fuehrt die gesamte Sequenz aus:
    1. Q halten (Rad oeffnet sich)
    2. Slot-Taste druecken (Item ausgewaehlt)
    3. Q loslassen (Item in der Hand)
    4. Linke Maustaste halten fuer die eingestellte Dauer (Item benutzt)
    5. H druecken (Waffe/Hand freimachen) — optional, pro Slot einstellbar

  Standard-Trigger-Tasten: 4, 5, 6 (Zahlentasten ueber den Buchstaben, nicht Numpad)
  Diese Tasten werden abgefangen waehrend QuickSelect aktiv ist.

  EINRICHTEN:
    1. Rechtsklick Tray -> Einstellungen -> QuickSelect... [PRO]
    2. "QuickSelect aktivieren" ankreuzen
    3. Auf Bind-Schaltflaeche klicken und Taste fuer jeden Slot druecken
    4. Rad-Slot-Nummer eintragen (1-9, entspricht deiner Spielzuordnung)
    5. LMB-Timer passend zum Item-Typ auswaehlen (T1-T6)
    6. H-Taste per Slot aktivieren falls erwuenscht
    7. OK klicken

  LMB-TIMER VOREINSTELLUNGEN:
    T1  1150ms  —  Adrenalinspritze
    T2  1650ms  —  Kraeuterverband / Verband
    T3  2150ms  —  Schildauflader
    T4  4150ms  —  Vita-Spritze
    T5  5150ms  —  Sofort-Schildauflader
    T6  frei    —  eigenen Wert einstellen (Standard 1000ms, max 8000ms)

  TIPPS:
    - Erst mit einem guenstigen Item testen bevor du es im Spiel nutzt.
    - Item nur teilweise benutzt? LMB-Timer erhoehen (naechsten T nehmen).
    - Rad schliesst zu frueh? Q-Haltezeit um 50ms erhoehen.
    - QuickSelect per Toggle-Taste pausieren wenn du in der Lobby
      oder im Chat tipps.
    - Slots 7–8 nutzen Mausbewegung: Q wird gehalten, Cursor faehrt auf
      die Rad-Position, Q wird losgelassen. Kein Tastendruck noetig.
    - H-Taste kann auch mit MB3, MB4 oder MB5 belegt werden.
    - Apply-Schaltflaeche speichert Einstellungen ohne Dialog zu schliessen.
    - Nach H-Druck (Holster) waehrend einer Nutzung kurz warten bevor
      QuickSelect erneut getriggert wird. Das Spiel haelt das Item kurz in
      einem Uebergangszustand — sofortiges Retriggern zieht das Item nur raus
      ohne es zu benutzen. Dies ist spiel-seitiges Verhalten.

QUICKSAVE (Pro)
  QuickSave zieht automatisch Items zwischen Inventar und Sicherheitstasche —
  mit einem einzigen Tastendruck oder Mausradscrollen.

  WAS KANN VERSCHOBEN WERDEN:
    - Items in Inventar-Slots 1–8 (alle QuickSelect-Slots und Waffen)
    - Items in Sicherheitstasche Slots 1–3
    - Richtung frei konfigurierbar: Slot → Tasche oder Tasche → Slot

  SO FUNKTIONIERT ES:
    1. Du drueckst den zugewiesenen Hotkey (oder scrollst das Mausrad)
    2. BrightRaider oeffnet das Inventar (Tab)
    3. Bewegt den Cursor zum Quell-Slot
    4. Haelt Linke Maustaste und zieht zum Ziel-Slot
    5. Laesst Linke Maustaste los
    6. Schliesst das Inventar (Tab)

  EINRICHTEN:
    1. Rechtsklick Tray → Einstellungen → QuickSave... [PRO]
    2. "An" fuer das gewuenschte Preset ankreuzen
    3. Auf Taste-Schaltflaeche klicken und Hotkey druecken
       (Tastatur, MB3/4/5 oder Mausrad Wheel↑/↓)
    4. "Von" einstellen — Quell-Slot (Slot 1–8 oder Tasche 1–3)
    5. "Nach" einstellen — Ziel-Slot (Slot 1–8 oder Tasche 1–3)
    6. "Oeffnen" und "Schliessen" aktivieren
    7. Apply oder OK klicken

  RICHTUNG UMKEHREN (⇄):
    Pro Preset aktivierbar. Erster Druck: Von → Nach. Zweiter Druck: Nach → Von.
    Nuetzlich z.B. fuer den Snap Hook: einmal in die Tasche, einmal heraus.

  TIMING (anpassen wenn Drag fehlschlaegt):
    Oeffnen   — Wartezeit nach Tab (Standard 250ms)
    Hover     — Zusatz-Wartezeit am Quell-Slot (Standard 0ms)
    Halten    — LMB-Haltezeit waehrend des Ziehens (Standard 0ms)
    Ablegen   — Wartezeit vor LMB-Loslassen am Ziel (Standard 120ms)
    Cooldown  — Mindestabstand zwischen zwei Ausloesungen (Standard 0ms)

  AN/AUS:
    Numpad /  →  QuickSave an/aus  (Numpad-Version)
    Ende      →  QuickSave an/aus  (Pfeiltasten-Version)
    Toast bestaetigt.

  BEKANNTE EINSCHRAENKUNG:
    Gelegentlich schlug der Drag-Vorgang fehl. Das ist ein bekanntes Verhalten
    des Unreal Engine Slate UI-Systems das Arc Raiders verwendet — dasselbe
    passiert auch beim normalen manuellen Ziehen im Inventar.
    Es kann nicht von aussen behoben werden. Einfach nochmal ausloesen.

CROSSHAIR-OVERLAY (Pro)

  Bildschirm. Funktioniert im Vollbild. Nutzt denselben Mechanismus

  An/aus: Numpad+ (Numpad-Version) / Einfg (Arrow-Version)

AUTO-HELLIGKEIT (Pro)
  Wenn aktiviert, analysiert BrightRaider 5 Zonen auf dem
  Bildschirm (Mitte gewichtet, 4 Ecken) per Median-Helligkeit.
  Basierend darauf wechselt es sanft zwischen Profilen.

  Aktivieren: Tray-Menue -> Auto-Helligkeit (Bildschirmanalyse)
  Kalibrierung: zwei Schritte — dunkelste Stelle messen,
  hellste Stelle messen, fertig.
  Das Kalibrierungsfenster erscheint unten am Bildschirm,
  ausserhalb aller 5 Messzonen — damit es das Ergebnis
  nicht verfaelscht.

  Zonen-Gewichtung: Tray-Menue -> Einstellungen -> Zonen...
    Jede der 5 Zonen (Mitte, oben links, oben rechts, unten links, unten rechts)
    hat einen Faktor von 0 bis 10. Hoeher = mehr Einfluss auf das Ergebnis.
    0 = Zone wird ignoriert (nuetzlich wenn HUD-Elemente eine Ecke verdecken).
    Standard: Mitte=2, alle Ecken=1.

  Siehe AutoBrightness_Guide.md fuer die komplette Kalibrierungs-Anleitung.

ALT-TAB AUTO-SWITCH (Kostenlos) — NEU in V1.0
  Pro Spiel automatisch Profil + FPS-Limit + Fadenkreuz aktivieren,
  sobald das Spiel in den Vordergrund kommt. Schluss mit manuellem
  Profil-Wechsel oder parallelem VibranceGUI.

  So funktioniert es:
    1. Spiel hinzufuegen: Einstellungen -> Game Profiles -> "Hinzufuegen..."
    2. Basis-Profil waehlen (Overrides optional: eigene Gamma/Kontrast/
       Vibrance/Hue/FPS-Limit nur fuer dieses Spiel)
    3. Spiel starten — BrightRaider erkennt es, wendet das Profil an,
       blendet das Fadenkreuz ein (falls konfiguriert), setzt das FPS-Limit
    4. Alt-Tab raus — Original-Ramps + Vibrance + Hue wiederhergestellt,
       Fadenkreuz versteckt. Tab zurueck — Spiel-Profil wieder aktiv
    5. Andere Spiele NICHT in der Liste bleiben im neutralen Zustand

  FPS-Limit pro Spiel:
    - NVIDIA: NvAPI DRS (Driver Settings) — sauber, kein DirectX-Hook
    - AMD: ADLX FRTC via amdadlx64.dll
    - Intel: keine oeffentliche API — UI zeigt einen Hinweis
    - Spart Strom + reduziert Luefter-Geraeusche: GPU rendert keine
      Frames mehr die der Monitor nicht darstellen kann.

PROCESS OPTIMIZER (Pro, opt-in) — NEU in V1.0
  Bei erkanntem Vordergrund-Spiel kann BrightRaider die Windows-
  Prozess-Prioritaet anheben und das Spiel auf physische CPU-Kerne
  pinnen (Hyperthreading aus). Glattere Frametimes wenn andere Tasks
  die Kerne belegen.

  Konfigurieren: Einstellungen -> Performance
    - "Spiel mit hoher Prioritaet laufen lassen" — High-Priority-Class
    - "Hyperthreading deaktivieren (nur physische Kerne)" — Affinitaet
      auf Kerne 0, 2, 4, ... (ueberspringt SMT-Geschwister)

  Opt-in — beide aus per Default. Setzt auf Normal-Prioritaet + volle
  Affinitaet zurueck beim Alt-Tab raus oder Spiel-Ende.

HOTKEY-PAUSE (Pro)
  Deaktiviert voruebergehend alle BrightRaider-Hotkeys.
  Die App laeuft weiter — sie fängt nur keine Tasten mehr ab.

  Umschalten: Rechtsklick Tray -> Einstellungen -> Hotkeys pausieren
  Ein Toast bestaetigt das Aktivieren/Deaktivieren.

GLOBAL EIN/AUS (Numpad Entf — Kostenlos)
  Zwei Modi, einstellbar unter Einstellungen -> App ->
  "Toggle OFF also resets the display":

    Angehakt (Default) = KOMPLETT AUS
      Versteckt jedes Overlay (Fadenkreuz, Map Scanner, Brightness-
      Debug), stellt deine Original-Gamma / -Vibrance / -Hue wieder
      her, pausiert Auto-Helligkeit und stoppt den Footstep Booster.
      Das Display verhaelt sich als waere BrightRaider gar nicht da.
      Nochmaliges Druecken wendet das aktive Profil wieder an.

    Nicht angehakt = NUR HOTKEYS PAUSIEREN
      Nur die Hotkeys werden ausgeblendet. Dein aktives Farbprofil,
      Overlays und FPS-Limit bleiben unangetastet. Nuetzlich wenn du
      die Tasten kurz fuer Chat / eine andere App brauchst, ohne den
      getunten Display-Zustand zu verlieren. Gleiches Verhalten wie
      V9.x's Page Down / Numpad Entf.

VIBRANCE RESTORE
  BrightRaider liest deine aktuelle GPU-Vibrance beim Start und stellt
  sie beim Beenden wieder her — dein Display kehrt immer in den
  Ausgangszustand zurueck. Profil 1 behaelt den von dir konfigurierten
  Wert (wird nicht automatisch auf den Hardware-Standard ueberschrieben).

MONITOR-AUSWAHL
  Standardmaessig wechseln alle Monitore gleichzeitig. Um nur
  einen Monitor zu aendern: Rechtsklick auf das Tray-Icon und
  den gewuenschten Monitor auswaehlen. Die Auswahl wird
  automatisch gespeichert.

HINWEISE
  - Numpad-Tasten sind belegt solange das Tool laeuft.
    Die normalen Zahlentasten (ueber den Buchstaben) sind
    NICHT betroffen.
  - Digitale Farbanpassung (NVIDIA) / Saettigung (AMD) wird
    im jeweiligen GPU Control Panel angezeigt.
    Gamma/Kontrast-Aenderungen werden dort NICHT angezeigt
    (das ist normal - sie nutzen eine andere API).
  - Im Tray-Menue wird unten die erkannte GPU angezeigt
    (NVIDIA, AMD oder Keiner).
  - Falls etwas komisch aussieht: einfach die App beenden.
    Alles wird automatisch auf Normal zurueckgesetzt.
